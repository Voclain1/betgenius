# Notes for Claude

## Design rules (from the owner)

- No coloured accent edges: no `border-l-*` / `border-r-*` stripe in a brand or
  status colour to mark a row, card or callout. Mark emphasis with the
  element's own background or an icon (for example an arrow button).
- No tinted pill backgrounds behind status text (e.g. `bg-brand/15` behind a
  "Champions League league stage" label). Write the text without a background.
- Pages should read as premium and editorial: strong type, generous spacing,
  real data only, nothing that goes stale silently.
